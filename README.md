# SIMPLE - MA Ghoyatul Jihad Karawang
Sistem Informasi Madrasah Pintar, Lengkap, dan Efektif (PHP native + MySQL). Semua data DUMMY.

## Menjalankan (Laragon)
1. Ekstrak ke `C:\laragon\www\simple-sekolah\`.
2. phpMyAdmin > tab SQL: jalankan `database/schema.sql`, lalu `database/seed.sql`.
3. Buka `http://localhost/simple-sekolah/login.php` (kamera scan hanya jalan di localhost / HTTPS).
4. Login: `admin` / `demo1234`. Akun lain: kepsek, wakasek, tu, guru.fiqih, guru.mtk, guru.bing (password sama).

## Ganti logo
Timpa `assets/img/logo.png` (nama file sama). Foto gedung login: `assets/img/gedung.webp`.

## Peran
ADMIN & TATA USAHA: ubah data. Kepala/Wakil: lihat semua. GURU: lihat siswa, scan, input izin/sakit/alpa.
